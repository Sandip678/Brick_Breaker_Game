# 🧱 Brick Breaker Game (Java)

A classic Brick Breaker (Arkanoid-style) game built in Java — control a paddle to bounce a ball and break all the bricks.

## 🛠️ Tech Stack
- Java (Core Java / Swing or AWT for graphics)
- IntelliJ IDEA project structure

## ✨ Features
> Update this list with your actual implemented features, for example:
- Paddle movement using keyboard (left/right arrow keys)
- Ball physics with wall and paddle collision
- Bricks break on hit, score increases
- Game over / win screen

## 🚀 How to Run
1. Clone the repository:
   ```
   git clone https://github.com/Sandip678/Brick_Breaker_Game.git
   ```
2. Open the project in IntelliJ IDEA / Eclipse.
3. Locate the file inside `src/` containing the `main()` method.
4. Run it directly from the IDE.
